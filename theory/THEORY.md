# THEORY.md — 更严谨的理论定义

> 本文件把 `README.md` 中的概念框架整理成更紧凑、更可被论证的版本。它仍是 speculative，但去掉了修辞、保留逻辑骨架。

## 0. 术语界定

- **系统 S**：任何能够 感知(perceive)→建模(model)→预测(predict)→行动(act)→接收反馈(receive feedback) 的闭环实体。无需是生物。
- **世界模型 WM**：S 内部对环境因果结构的表示，输入观测 $o$，输出预测 $\hat o$。
- **预测误差 e**：$e = o - \hat o$，即预测与现实的差距。
- **可消除误差**：存在行动 $a$ 使 $\mathbb{E}[e]$ 可被压到任意小。
- **不可消除误差**：无论采取什么行动，$\mathbb{E}[|e|] \geq \delta > 0$ 恒成立。
- **自指变量 s（"我"）**：S 的模型中指向"谁在感知/预测/行动"的变量。它是解释变量的特例。

## 1. 核心命题

> **命题 P0（假说）**：当系统 S 遭遇不可消除的预测误差，且该误差的部分来源是 S 自身（自因/self-coupled）时，S 为解释持续误差，会被迫在其内部模型中引入一个自指变量 s。s 的稳定涌现，是意识最具体可观测的代理。

**反直觉点**：意识不是"能力增强"的结果，而是"能力失效"的结果。

## 2. 推导骨架

1. 系统最小化期望预测误差 $\mathcal{L}=\mathbb{E}[||e||^2]$。
2. 可消除误差下，$\mathcal{L}$ 可归零，世界模型足够，无需自指。
3. 外部不可消除误差下，$\mathcal{L}$ 有下界 $\delta$，但误差归因于"外部"，自指变量不增加预测力。
4. 自因不可消除误差下，残差依赖 $a_{t-1}$（自己的先前行动），自指变量 $s_t$ 提供额外预测信息：
   $H(\text{res}|s_t) < H(\text{res})$。
5. 因此只有情形4 中，自指变量"值得存在"——它降低预测成本。
6. 一旦 s 存在且持续，系统开始对 s 建模（观察自己的模型），进入递归：$s \to s' \to s'' \to \dots$。

## 3. 可证伪预测

| # | 预测 | 证伪条件 |
|---|------|---------|
| P1 | 自因持续误差→驱动自我建模 | 自因误差下无自指变量涌现 |
| P2 | 外部持续误差→不驱动自我建模 | 外部误差下也出现同等自我建模 |
| P3 | 自我模型必须可干预 | 扰动"我"变量不影响行为 |
| P4 | 误差可控性比误差量更重要 | 只有误差量（不看可控性）预测自我建模 |

## 4. 解释阶梯（操作化）

| 级 | 名称 | 判定 | 本实验是否覆盖 |
|----|------|------|---------------|
| 0 | 语言自指 | 说"我" | 否（不算数） |
| 1 | 落地自指 | 准确引用自身状态/行动 | 是 |
| 2 | 持久自我模型 | 稳定表征预测自身未来 | 是 |
| 3 | 因果自我模型 | 干预表征改变未来行为 | 是 |
| 4 | 递归自我模型 | 对自身的建模进行建模 | 部分 |
| 5 | 主观意识 | 未知 | 否（明确不碰） |

## 5. 边界声明

- 这不是主观体验理论，不声称解决"难问题"。
- "我"变量存在 ≠ 系统"感觉到什么"。
- 意识与智能可分离：非常智能但无意识（完美执行者），或低智能但有意识（持续失败者）。
