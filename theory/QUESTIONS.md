# QUESTIONS.md — 尚未解决的问题

这些是本假说目前无法回答、最需要社区帮助的问题。

## 1. 为什么"自我模型"会产生主观体验？
一个系统拥有 `I` 变量，并不自动证明它"感觉到了什么"。这是**难问题（hard problem）**。本框架只解释了"为什么需要 '我'" ，没有解释"为什么 '我' 会感觉"。

## 2. 什么程度的递归才足够？
- 单层自我模型（预测自身状态）够吗？
- 还是必须递归（模型对模型建模，即"我知道我知道"）？
- 是否存在一个临界递归深度，超过它主观体验涌现？没有边界条件。

## 3. Bug 必须是哪一类？
并非所有误差都逼出"我"。可能只有
- **持续**的（跨多步不消失）
- **不可行动消除**的（行动无效）
- **与自身状态相关**的（自因）误差
才有效。但"必要且充分"的类别未刻画。

## 4. 意识是否需要身体？
- 若环境互动是产生不可消除误差的必要条件 → 纯软件 AI 无法产生等价"我"。
- 若自因建模是关键 → 身体只是附带，纯软件也能。
两者未知。实验 C 若在纯软件 agent 中观察到自指变量涌现，则支持后者。

## 5. 智能与意识可否分离？
本框架允许：
- 非常智能但无意识（完美执行者，无误差）
- 低智能但有意识（持续失败者）
这挑战"智能≈意识"的直觉。是否可被实验分离？

## 6. 误差量 vs 可控性，哪个驱动自我建模？
实验 B 的玩具结果显示 B2（自因）selfMSE 最高，但误差量也比 B1（外部）低。**无法区分是"误差可控性"还是"误差量"在起作用**。需要匹配误差量的对照实验。

## 7. "我"是变量还是实体？
最终问题：递归建模出的"我"，是模型里的一个变量，还是某种独立的实体？本框架倾向变量论，但这不是结论。
